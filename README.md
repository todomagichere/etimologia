# Etimox

Juego diario de etimologías: descubre el significado de las raíces que forman palabras habituales.

Es una aplicación estática, sin dependencias ni proceso de compilación. Para abrirla basta con servir esta carpeta desde cualquier servidor web estático, por ejemplo:

```sh
python3 -m http.server 8080
```

Después abre `http://localhost:8080`.
